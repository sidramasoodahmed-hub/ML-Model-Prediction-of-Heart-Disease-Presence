**Heart Disease Prediction Using Machine Learning**
This project develops a machine learning model to predict the presence of heart disease using patient clinical and demographic data. The notebook includes data cleaning, exploratory data analysis, model training, and performance evaluation.

**Project Overview**
The goal is to build and compare classification models that can identify patients at risk of heart disease. The workflow demonstrates practical skills in data preprocessing, visualization, and predictive modeling.

**Methods**
1. Data cleaning and preparation
2. Exploratory data analysis (distribution plots, correlations, feature patterns)
3. Training multiple machine learning models
4. Model evaluation using accuracy and other metrics

**Technologies Used**
1. Python
2. Pandas
3. NumPy
4. Matplotlib & Seaborn
5. Scikit-learn
6. Jupyter Notebook

**Purpose**
This project demonstrates the end-to-end process of building interpretable ML models for a real-world healthcare classification problem.

This project demonstrates the end-to-end process of building interpretable ML models for a real-world healthcare classification problem and is part of my Spring 2025 machine learning coursework.
